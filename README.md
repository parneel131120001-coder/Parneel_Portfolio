# Parneel Saharan - Scientific Research Portfolio

Welcome to the personal research portfolio of **Parneel Saharan**, MSc Candidate in Plant Sciences (Horticulture) at **Tokyo University of Agriculture** and Exchange Researcher at **Wageningen University & Research (WUR)**.

## 🌿 Overview

This portfolio showcases academic training, peer-reviewed scientific publications, research projects (including master's thesis work on cryptochrome photoreceptors and seed priming direct-sowing protocols), prestigious scholarships/grants, and laboratory competencies.

Built with **React 19**, **TypeScript**, and **Vite**, featuring an interactive botanical dark-mode interface and centralized data driven by `src/data/master_profile.json`.

## 🏃‍♂️ Running Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Open in browser**:
   Navigate to [http://localhost:5173](http://localhost:5173).

4. **Production Build**:
   ```bash
   npm run build
   ```

## 🚀 Deployment to Vercel

This repository is optimized for one-click deployment on [Vercel](https://vercel.com/):
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
